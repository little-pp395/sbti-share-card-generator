# v0.1.0

First public release of `sbti-share-card-generator`.

## Highlights

- launched the initial Next.js + TypeScript + Tailwind MVP
- added live share-card preview for SBTI-style results
- added editable fields for type code, title, subtitle, tagline, and accent color
- added preset result types
- added client-side PNG export
- added README, example asset, roadmap, contributing guide, and GitHub issue templates

## Notes

- this repository is intentionally focused on the share-card generator only
- the full interactive SBTI experience lives at `https://sbtitest.co`
