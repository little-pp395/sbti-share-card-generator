# Contributing

Thanks for contributing to `sbti-share-card-generator`.

## What Fits This Repo

Good contributions for this project are:

- new card presets or theme variations
- card layout improvements
- export quality fixes
- accessibility and responsiveness improvements
- README or setup clarity improvements

Please keep scope tight. This repository is for the share-card generator only, not the full SBTI product.

## Local Setup

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Before Opening a PR

- keep the project lightweight
- avoid adding backend complexity unless clearly necessary
- avoid unrelated refactors
- make sure `npm run build` passes
- update docs if behavior or setup changes

## Design Direction

The visual style should stay:

- clean
- modern
- slightly meme-aware
- good for screenshots and social sharing

Avoid making it feel too corporate or too busy.

## Pull Request Notes

When opening a PR, include:

- what changed
- why it helps
- a screenshot or exported card if the UI changed

## Issues

If you want to contribute but are unsure where to start, open a feature request or a new type idea first.
